Write up

Using this dataset, we want to focus on the effects of El Nino and El Nina: creating a visualization of the changes in temperature, sea surface temperature, and sea level over time. The interactive website aims to show how these natural events create changes to the climate through the temperature and sea level differences. The website will include a which covers the changes to the climate where someone can adjust the filters/settings to create different visuals surrounding these effects on a map. Currently we have a line graph that shows the annual Sea Surface, Sea Level Height and Precipitation over time. We have them in a line graph so readers can see how they affect each other and whether or not they follow the same trends. And we also plan to have a vector flow map to graph how sea surface temperature moves and navigate in the Pacific Ocean to see how El Nino and El Nina affect the water.

The most challenging part of our project to design will be the website layout and chart design. Our topic includes temperature, sea surface temperature, sea level, and precipitation, so we need to present a lot of data in a clear way. The charts also need to help readers compare different climate patterns over time without feeling overwhelming. Another challenge is making the interactive filters easy to use, so users can explore El Nino and El Nina effects without getting confused.
